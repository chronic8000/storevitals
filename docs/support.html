Support

Publisher: Philip Sempers · Product: StoreVitals (Microsoft Store)

How to get help

  1. Read the in-app Settings guidance for Entra / Partner Center setup.
  2. Follow the account setup guide in the project documentation (docs/ACCOUNT_SETUP.md).
  3. Open a GitHub issue on the StoreVitals repository: github.com/chronic8000/storevitals/issues

What to include

  • StoreVitals version (from the package / About if shown)
  • Windows version and PC architecture (x64 or ARM64)
  • Whether you use a work/school or personal Microsoft account
  • Relevant log lines (never paste client secrets or passwords)

Common issues

  • Sync 401 — Partner Center → User management → Microsoft Entra applications → role Manager.
  • Sign-in redirect errors — use device code, or fix Entra mobile/desktop redirect URIs.
  • Empty long date ranges — run Full sync; empty early days are normal if the app is younger than the selected range.
